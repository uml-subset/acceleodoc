AQL Language Reference

This is a local copy of the Acceleo Query Language documentation with injected anchors for use by acceleodoc cross-reference links.

Services available for all types

Object + String : String

Returns the concatenation of the current object (as a String) and the given string.

ExpressionResult
'times ' + 42'times 42'

Object <> Object : Boolean

Indicates whether the two objects are different.

ExpressionResult
'Hello' <> 'World'true
'Hello' <> 'Hello'false

Object = Object : Boolean

Indicates whether the two objects are equal.

Object.oclAsType(Object) : Object

Casts the current object to the given type. Contrary to Acceleo 3, the type is ignored and the object is returned directly.

Object.oclIsKindOf(Object) : Boolean

Evaluates to true if the type of the object conforms to the type classifier — that is, o1 is of type classifier or a subtype of it.

ExpressionResult
anEPackage.oclIsKindOf(ecore::EPackage)true
anEPackage.oclIsKindOf(ecore::ENamedElement)true

Object.oclIsTypeOf(Object) : Boolean

Evaluates to true if the object is of exactly the type classifier, not a subtype.

Object.toString() : String

Returns a string representation of the current object.

ExpressionResult
42.toString()'42'

Object.trace() : String

Returns a string representation of the current AQL evaluation environment.

Services available for Collections

Collection->any( x | ... ) : Object

Gets the first element for which the lambda evaluates to true.

ExpressionResult
Sequence{'a','b','c'}->any(str | str.size() = 1)'a'

Collection->asOrderedSet() : OrderedSet

Returns an OrderedSet representation of the collection.

Collection->asSequence() : Sequence

Returns a Sequence representation of the collection.

Collection->asSet() : OrderedSet

Returns a set representation, removing duplicates.

Sequence->at(Integer) : Object

Returns the element at the specified position (1-based index).

ExpressionResult
Sequence{'a','b','c'}->at(1)'a'

Collection->collect( x | ... ) : Collection

Returns a collection containing the result of applying the lambda on all elements, maintaining order.

ExpressionResult
Sequence{'a','b','c'}->collect(str | str.toUpper())Sequence{'A','B','C'}

Collection->concat(Collection) : Collection

Returns the concatenation of the current collection with the given collection.

Collection->count(Object) : Integer

Returns the number of occurrences of the given object in the collection.

Collection->excludes(Object) : Boolean

Indicates if the collection does not contain the given object.

Collection->excludesAll(Collection) : Boolean

Indicates if no elements from the second collection are in the first.

Collection->excluding(Object) : Collection

Returns the collection with the given object removed.

Collection->exists( x | ... ) : Boolean

Indicates if there exists an element for which the lambda evaluates to true.

ExpressionResult
Sequence{'a','b','c'}->exists(str | str.size() > 5)false

Collection->filter(EClassifier) : Collection

Keeps only instances of the given EClassifier.

Collection->first() : Object

Returns the first element of the collection.

Collection->forAll( x | ... ) : Boolean

Indicates if all elements validate the given lambda.

ExpressionResult
Sequence{'a','b','c'}->forAll(str | str.size() = 1)true

Collection->includes(Object) : Boolean

Indicates if the collection contains the given object.

Collection->includesAll(Collection) : Boolean

Indicates if all elements of the second collection are in the first.

Collection->including(Object) : Collection

Returns the collection with the given object added.

Collection->indexOf(Object) : Integer

Returns the index of the given object (1-based).

Collection->insertAt(Integer, Object) : Collection

Inserts the given object at the given position.

Collection->intersection(Collection) : Collection

Returns elements present in both collections.

Collection->isEmpty() : Boolean

Returns true when the collection is empty.

Collection->isUnique( x | ... ) : Boolean

Indicates if the lambda gives a different value for all elements.

Collection->last() : Object

Returns the last element of the collection.

Collection->notEmpty() : Boolean

Returns true when the collection is not empty.

Collection->one( x | ... ) : Boolean

Indicates if one and only one element validates the lambda.

Collection->prepend(Object) : Collection

Inserts the given object at the first position.

Collection->reject( x | ... ) : Collection

Returns a filtered collection keeping only elements for which the lambda evaluates to false.

ExpressionResult
Sequence{'a','b','c'}->reject(str | str.equals('a'))Sequence{'b','c'}

Collection->reverse() : Collection

Returns the collection in reversed order.

Collection->select( x | ... ) : Collection

Returns a filtered collection keeping only elements for which the lambda evaluates to true.

ExpressionResult
Sequence{'a','b','c'}->select(str | str.equals('a'))Sequence{'a'}

Collection->sep(Object) : Sequence

Inserts the given separator between each element of the collection.

Collection->size() : Integer

Returns the number of elements in the collection.

ExpressionResult
Sequence{'a','b','c'}->size()3

Collection->sortedBy( x | ... ) : Collection

Returns the collection ordered by the result of the lambda.

ExpressionResult
Sequence{'aa','bbb','c'}->sortedBy(str | str.size())Sequence{'c','aa','bbb'}

Sequence->subSequence(Integer, Integer) : Sequence

Returns a subset of the sequence between the two given indices.

OrderedSet->subOrderedSet(Integer, Integer) : OrderedSet

Returns a subset of the ordered set between the two given indices.

Collection->sum() : Number

Sums elements of the collection.

Collection->union(Collection) : Collection

Returns a collection containing all elements of both collections.

Services available for EObjects

EClass.allInstances() : Sequence{EObject}

Returns all instances of the EClass.

EObject.eAllContents() : Sequence{EObject}

Returns a sequence of all EObjects recursively contained in the root eObject.

EObject.eClass() : EClass

Returns the EClass (metaclass) of the specified EObject.

EObject.eContainer() : EObject

Returns the container (parent) of the specified EObject.

ExpressionResult

EObject.eContainerOrSelf(EClass) : EObject

Returns self or the first container matching the given type.

EObject.eContents() : Sequence{EObject}

Returns the direct children of the specified EObject.

EObject.eCrossReferences() : Object

Returns the list of all EObjects cross-referenced from the receiver.

EObject.eGet(String) : Object

EObject.eInverse() : OrderedSet{EObject}

Returns the set containing the inverse references of this object.

Services available for Strings

String.concat(String) : String

Returns the concatenation of the current string and the given string. Equivalent to +.

String.contains(String) : Boolean

Returns true if the current String contains the given string.

String.endsWith(String) : Boolean

Returns true if the current String ends with the given string.

String.equalsIgnoreCase(String) : Boolean

Returns true if the strings are equal ignoring case.

String.first(Integer) : String

Returns the first n characters of the string.

String.index(String) : Integer

Returns the index of the first occurrence of the substring (1-based), or -1.

String.isAlpha() : Boolean

Returns true if the string consists only of alphabetical characters.

String.isAlphaNum() : Boolean

Returns true if the string consists only of alphanumeric characters.

String.last(Integer) : String

Returns the last n characters of the string.

String.lastIndex(String) : Integer

Returns the index of the last occurrence of the substring (1-based), or -1.

String.matches(String) : Boolean

Returns true if the string matches the given regular expression.

String.prefix(String) : String

Returns the current string prefixed with the given prefix.

String.replace(String, String) : String

Replaces the first substring matching the regex with the replacement.

String.replaceAll(String, String) : String

Replaces all substrings matching the regex with the replacement.

String.size() : Integer

Returns the length of the string.

ExpressionResult
'HelloWorld'.size()10

String.startsWith(String) : Boolean

Returns true if the string starts with the given string.

String.strcmp(String) : Integer

Returns a negative, zero, or positive integer depending on alphabetical ordering.

String.strstr(String) : Boolean

Returns true if the given string is found in the current string.

String.substitute(String, String) : String

Substitutes the first occurrence of the substring with the replacement.

String.substituteAll(String, String) : String

Substitutes all occurrences of the substring with the replacement.

String.substring(Integer, Integer) : String

Returns the substring from lower to upper inclusive (1-based).

ExpressionResult
'HelloWorld'.substring(1, 5)'Hello'

String.toInteger() : Integer

Returns the integer value of the string.

String.toLower() : String

Returns the string with all characters in lower case.

String.toLowerFirst() : String

Returns the string with the first character in lower case.

String.toReal() : Real

Returns the real value of the string.

String.toUpper() : String

Returns the string with all characters in upper case.

String.toUpperFirst() : String

Returns the string with the first character in upper case.

String.tokenize(String) : Sequence{String}

Splits the string using the given delimiter into a collection of strings.

String.trim() : String

Trims leading and trailing whitespace from the string.
